Explication de la formule de difficulté

Difficulty = w1 * recent_again_rate + w2 * lapse_rate + w3 * (1 - mastery).

recent_again_rate = % d’“again” dans la fenêtre glissante (revlog). lapse_rate = part de lapses historiques. mastery = (recent + mature) / total.
